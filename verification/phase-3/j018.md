# J-018: pgvector extension + HNSW index migration

## Status
COMPLETE

## Objective
Ensure a stock empty Postgres (with pgvector installed, but extension not created) migrates successfully via `pnpm db:migrate` alone, and `document_embeddings` has the HNSW cosine index.

## Mechanism Chosen
I implemented mechanism (a): added a pre-step executing `CREATE EXTENSION IF NOT EXISTS vector;` before `migrate()` in `src/core/database/migrator.ts`. This was preferred because extension creation is an environment privilege setup, not part of the schema history itself (it's not easily represented in standard drizzle snapshots).

I added error handling to catch insufficient-privilege errors (code `42501`) and clearly direct the user to run `database/bootstrap.sql` as a superuser.

I also added the `hnsw` index for `document_embeddings` directly to `database/schema/index.ts` using drizzle-orm `0.45` custom-op support:
`index("idx_document_embeddings_embedding").using("hnsw", table.embedding.op("vector_cosine_ops"))`

This successfully generated `database/drizzle/0004_abandoned_black_crow.sql`.
