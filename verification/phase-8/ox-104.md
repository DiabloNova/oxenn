## Fail-Closed Demonstration

Running `tests/features/acquisition/integration/run-all.ts` locally with `DATABASE_URL` unset and `CI=true` appropriately exits with 1.

```bash
$ CI=true DATABASE_URL="" npx tsx tests/features/acquisition/integration/run-all.ts || echo "Failed with exit code $?"
❌ acquisition integration suite failed: DATABASE_URL is not set under CI
Failed with exit code 1
```

When run locally without `CI=true`, it exits 0 gracefully:

```bash
$ DATABASE_URL="" npx tsx tests/features/acquisition/integration/run-all.ts
⚠️ acquisition integration suite skipped: DATABASE_URL is not set
```
