# Verification for J-014 (Phase 2 - Fail-Closed Hardening)

## Objective
Remove fail-open DB paths (`MockPoolClient` + hardcoded URL) to ensure all DB unavailability throws a clear, sanitized error with zero silent-empty degradation.

## Summary of Changes
- Extracted `sanitizeErrorMessage` to a shared utility (`src/core/utils/error-sanitizer.ts`).
- Created `DatabaseUnavailableError` class.
- Refactored `PostgresClient` to require `DATABASE_URL` (removed `aeo_saas` fallback) and wrapped connect and query errors with `DatabaseUnavailableError`, ensuring sanitized outputs.
- Moved `MockPoolClient` to `tests/helpers/mock-pool-client.ts`.
- Removed silent `null` continuation in `runWithTenantContext`.
