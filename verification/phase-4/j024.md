# J-024 Verification Report: Schema-Derived Tenant Whitelist & Robust Query Matcher

## Executive Summary
J-024 eliminates hardcoded tenant table list drift and hardens SQL tenant-scoped query detection. The hardcoded list in `src/core/database/tenant-context/index.ts` has been replaced with a generated export in `src/core/database/tenant-tables.generated.ts` derived dynamically from Drizzle schema snapshots (`database/drizzle/meta/`). A CI verification script (`scripts/database/verify-tenant-tables.ts`) asserts set-equality on every commit and build. `isQueryTenantScoped` was hardened with comment/string-literal stripping and boundary-aware negative lookbehind/lookahead regex.

## 4. Broken-Path Inventory for J-029

Gating the 16 previously-ungated tables identifies real call-sites where queries are executed before tenant/system context is established. These are documented for J-029 resolution:

1. **`ApiKeyRepository.findByPrefix(prefix: string)`**
   - **Location**: `src/features/public-api/repositories/api-key-repository.ts`
   - **Table**: `api_keys`
   - **Issue**: API key lookup happens during request authentication to determine tenant identity before `TenantContext` is established. Needs system-context wrapper (`runWithSystemContext`) or pre-auth system client in J-029.

2. **`PostgresTenantRepository.findBySlug(slug: string)` / `findById`**
   - **Location**: `src/features/admin/infrastructure/persistence/postgres/index.ts`
   - **Table**: `organizations`
   - **Issue**: Organization resolution by slug/ID during domain lookup or administrative tasks runs before tenant context context-switch. Needs explicit `runWithSystemContext`.

3. **`WebsiteRepository` / `PageRepository` / `KeywordRepository` / `TopicRepository` / `CompetitorRepository`**
   - **Location**: `src/features/ai-intelligence/repositories/index.ts`
   - **Tables**: `websites`, `pages`, `keywords`, `topics`, `competitors`
   - **Issue**: Background tasks or system crawlers accessing domain entities directly without active `TenantContext`. Need explicit `runWithTenantContext` or system execution mode in worker handlers.
