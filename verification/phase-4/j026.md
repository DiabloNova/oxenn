# J-026: Crawl subsystem tenant-id normalization (text → uuid)

## Objective
Uniform `uuid` tenant identity for the crawl subsystem, updating `crawlJobs`, `crawlResults`, and `crawlCache` in the database schema to use `uuid` mapping to organizations, replacing `text` and `textTenantPolicy`.

## Phase 1: Call-site trace (tenant_id)
1. **Schema**
   - `database/schema/index.ts`: `crawlJobs.tenantId`, `crawlResults.tenantId`, `crawlCache.tenantId` (and their `textTenantPolicy()`).
2. **Repositories (src/features/acquisition/infrastructure/persistence/postgres/)**
   - `crawl-job-repository.ts` (returns `tenant_id: string`, uses TS string).
   - `crawl-result-repository.ts` (returns `tenant_id: string`, uses TS string).
   - `crawl-cache-repository.ts` (returns `tenant_id: string`, uses TS string).
   - `dispatcher-repository.ts` (returns `tenant_id: string`, uses TS string).
3. **Tests / Mocks**
   - Tests in `tests/features/acquisition/integration/run-all.ts`, `tests/features/acquisition/http-provider.test.ts`, `tests/features/acquisition/providers.test.ts`, `tests/features/acquisition/router.test.ts`.

## Phase 2: Schema Migration Generation
Since `drizzle-kit generate` requires an interactive terminal when generating schema differences that result in data loss or rebuilding (changing text to uuid), and we strictly adhere to the fresh-DB doctrine (where replaying on a fresh DB is what matters), we generated a custom migration using `pnpm db:generate --custom` and injected the necessary type casting and foreign key references.

```sql
ALTER TABLE "crawl_jobs" ALTER COLUMN "tenant_id" SET DATA TYPE uuid USING "tenant_id"::uuid;
ALTER TABLE "crawl_results" ALTER COLUMN "tenant_id" SET DATA TYPE uuid USING "tenant_id"::uuid;
ALTER TABLE "crawl_cache" ALTER COLUMN "tenant_id" SET DATA TYPE uuid USING "tenant_id"::uuid;
...
```

## Phase 3: Call-site conversions
Call sites were updated correctly in tests to replace string dummies (e.g. `ws-tenant-a`) with valid UUID equivalents so that PostgreSQL would not throw a syntax error when inserting or querying on the `uuid` typed columns. The codebase's repositories were implicitly compatible with the TS `string` mapped via Drizzle's UUIDs.
