# 089 — VER-008: Database Vitest project can report success with zero tests in the current tree

## Source
- Finding ID: VER-008
- Original audit: ai_tasks/verification-folder-audit.md
- Status: historical evidence or verification gap as described in the original audit; unsafe probes are not authorized for execution

## Problem
The DB Vitest project includes tests/db/**/*.test.ts and sets passWithNoTests=true. The audited tree contains no tests/db files, and package.json exposes test:db, so that command can exit successfully without executing any DB tests.

## Evidence
Evidence: vitest.config.ts DB project includes tests/db and passWithNoTests true; tests/db is empty; package.json exposes test:db.

## Affected files and paths
vitest.config.ts, package.json, tests/db, CI database gates.

## Impact
A green test:db result can be a false green and does not prove database integration coverage.

## Recommended solution
Make the DB project fail on zero discovered tests when it is a required gate. Until a suite exists, make the command explicitly report not configured/disabled rather than successful. Add real database tests against a verified disposable PostgreSQL service and ensure CI distinguishes skip from pass. Coordinate with RF-003 and TST-006.

## Architecture alignment
Persistence, RLS, and provenance contracts require real adapter/integration verification, not an empty project.

## Verification criteria
Zero discovered tests cannot pass a required DB gate; CI runs real DB tests or reports an explicit non-green skip.

RF-003, TST-001, TST-006
