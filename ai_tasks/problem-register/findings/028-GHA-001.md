# 28 — GHA-001: GitHub Actions workflow versions use Node 20-runtime releases and emit deprecation warnings

## Source
- Finding ID: `GHA-001`
- Original audit: `ai_tasks/github-folder-audit.md`
- Status: as recorded in the original folder audit; any conditional claims remain subject to revalidation

## Problem
The two tracked workflows use major-version v4 releases of checkout, setup-node, and upload-artifact. CI logs for main commit `7bd2b6ba04e18abbcaf772fac63f29c465a45a42` reported Node.js 20 deprecation and forced Node 24 execution for these actions.

## Evidence
- `.github/workflows/ci.yml` uses checkout/setup-node v4 in build, unit, and isolation jobs.
- `.github/workflows/capture-regression-baseline.yml` uses checkout/setup-node/upload-artifact v4.
- CI run `42181198077` emitted Node 20 deprecation warnings; workflows completed at that commit.

## Affected files and paths
- `.github/workflows/ci.yml`
- `.github/workflows/capture-regression-baseline.yml`

## Impact
The workflows currently rely on a compatibility path that is generating warnings and may be removed. A future runner change could break CI unexpectedly.

## Recommended solution
1. Review official action release notes and supported runtime/input changes.
2. Upgrade to supported Node-24-native releases as appropriate, verifying each action's official repository and exact version.
3. Preserve the application's Node runtime requirement (Node 22) unless a separate runtime decision is approved; action runtime and application runtime are distinct.
4. Update both workflows through one coordinated version matrix to avoid inconsistent action versions.
5. Run all relevant jobs and verify artifact upload/download, checkout behavior, cache behavior, and permissions.
6. Record the selected action versions and their immutable references in the workflow supply-chain policy.

## Architecture alignment
CI is part of the verification/evaluation layer. Updating action runtimes must not change the application's runtime or silently weaken verification gates.

## Verification criteria
No Node 20 action-runtime warnings remain; all jobs pass on the selected runner; artifact behavior and application Node version remain correct.
