# 044 — SCR-005: test-domain.ts launches asynchronous checks without awaiting the sequence

## Source
- Finding ID: `SCR-005`
- Original audit: `ai_tasks/scripts-folder-audit.md`
- Status: as recorded in the source audit; dependent behavior remains subject to revalidation

## Problem
The custom `runTest` helper invokes async callbacks and attaches detached `.then/.catch` handlers without returning or awaiting their promises. Later checks can start while earlier checks are still running, so the script lacks a single completion boundary and can produce misleading summaries.

## Evidence
- `scripts/test-domain.ts:18-38` uses a synchronous helper around async callbacks.
- Async repository and observation checks launch at `:164-186` and `:211-285`.

## Affected files and paths
- `scripts/test-domain.ts`
- Package scripts or CI entry points that invoke it.
- Domain fixtures, shared state, and teardown.

## Impact
Checks may overlap unexpectedly, race on shared services/state, or outlive the script's reported completion. A passing log does not prove every check completed.

## Recommended solution
1. Verify whether this script is still invoked by package scripts or CI before deciding to modernize or retire it.
2. Prefer the repository's supported test runner and standard assertions/fixtures.
3. If retained as a custom harness, make the runner async and await each test or use an explicitly bounded Promise.all only for isolated tests.
4. Aggregate results after every promise settles and return non-zero if any check fails.
5. Add fixture isolation and deterministic teardown; ensure no test mutates shared external state unexpectedly.
6. Test that a delayed failure is awaited and cannot be reported as success.

## Architecture alignment
Test evidence must be deterministic and accurately represent completed work; async domain checks should run through the same observable test contract as the rest of the repository.

## Verification criteria
All checks complete before process exit; failures propagate; summaries match executed tests; no detached promises remain.
