# 084 — VER-003: Reference-matrix success relies partly on heuristic text matching rather than authoritative ownership

## Source
- Finding ID: VER-003
- Original audit: ai_tasks/verification-folder-audit.md
- Status: historical evidence or verification gap as described in the original audit; unsafe probes are not authorized for execution

## Problem
A historical reference matrix is generated from a Drizzle snapshot and acknowledges that consumer matches are heuristic text matches that may include prose or non-database references. The current matrix also classifies five organization-owned junction tables as Global.

## Evidence
Evidence: phase-6/j035 describes snapshot generation and heuristic consumer matches; DOC-001 records incorrect global classification.

## Affected files and paths
Historical phase-6 matrix report, current reference matrix generator, canonical ownership contract.

## Impact
A zero-orphan result may only prove that heuristic matching found no unmatched strings; it does not prove domain ownership, tenant scope, or RLS completeness.

## Recommended solution
Keep heuristic references as discovery hints, not authoritative proof. Create explicit table ownership metadata and typed repository/consumer references. Validate generated matrix against an independent expected ownership inventory. Report unresolved/heuristic matches as uncertain rather than verified. Separate ownership, declared policy, migration coverage, and runtime tests.

## Architecture alignment
Generated inventory is supporting evidence; canonical domain contracts and enforcement gates are authoritative.

## Verification criteria
The matrix labels evidence quality; independent ownership oracle catches missing tables; heuristic text matches cannot certify tenant isolation.
