# 038 — PUB-005: Generic placeholder and starter-template assets remain in the public tree

## Source
- Finding ID: `PUB-005`
- Original audit: `ai_tasks/public-folder-audit.md`
- Status: as recorded in the original public-folder audit; incomplete source-search limitations are preserved

## Problem
The public directory contains generic placeholders and starter-template graphics, including placeholder logos/user photos, a 1×1 placeholder image, generic file/globe/next/vercel/window SVGs. Their existence is confirmed, but incomplete source search prevents classifying every file as unused.

## Evidence
- The complete public tree inventory lists these files.
- Some assets are clearly generic placeholders or framework starter graphics.
- Repository source-reference search was incomplete.

## Affected files and paths
- `public/placeholder-logo.png`
- `public/placeholder-logo.svg`
- `public/placeholder-user.jpg`
- `public/placeholder.jpg`
- `public/placeholder.svg`
- `public/file.svg`, `globe.svg`, `next.svg`, `vercel.svg`, `window.svg`.

## Impact
A user-facing route may accidentally show generic or starter branding, while unused files increase asset clutter and can be mistaken for approved product artwork.

## Recommended solution
1. Trace all static and dynamic references to each asset, including fallback components and content configuration.
2. Classify each as active placeholder, required fallback, starter residue, or obsolete.
3. Replace any user-visible placeholder with approved brand/product artwork before production use.
4. Remove only confirmed-unused starter residue in a separately approved cleanup.
5. Keep required fallback assets only when the UI behavior and ownership are documented and tested.

## Architecture alignment
The frontend should use intentional product assets and must not imply a finished product experience through generic placeholder media.

## Verification criteria
No user-facing production path displays unintended starter artwork; every retained fallback has an explicit purpose; unused assets are removed only with reference evidence.
