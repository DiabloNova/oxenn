# 27 — FNT-004: Typography documentation claims BoxFace is the active English title font, but the app uses Peyda

## Source
- Finding ID: `FNT-004`
- Original audit: `ai_tasks/font-folder-audit.md`
- Status: as recorded in the original folder audit; any conditional claims remain subject to revalidation

## Problem
Redesign documentation says local BoxFace is configured for English titles. The current font configuration imports Yekan Bakh and Peyda only, and `globals.css` assigns the Peyda display variable to headings. A historical commit that used BoxFace for an SEO navbar does not prove it remains active.

## Evidence
- `src/config/fonts.ts` defines Yekan Bakh and Peyda, not BoxFace.
- `globals.css` assigns the Peyda display variable to headings.
- Historical BoxFace usage does not establish current configuration.

## Affected files and paths
- Design/redesign typography documentation.
- `src/config/fonts.ts`
- `globals.css`
- Localized layouts and visual regression tests.

## Impact
Design decisions and implementation diverge. Designers and engineers may assume a font is active when it is not, causing inconsistent typography and inaccurate acceptance criteria.

## Recommended solution
1. Confirm the approved typography system and whether English titles require a separate display family.
2. If Peyda is the intended current heading face, correct the documentation and preserve the existing implementation.
3. If BoxFace is deliberately approved, first resolve FNT-002 licensing, add it through the central font loader, assign it only to the intended locale/typography tokens, and validate actual rendering.
4. Do not introduce font-family overrides in scattered components; use the shared design tokens and locale-aware layout configuration.
5. Add visual checks for Persian and English headings at representative weights and breakpoints.

## Architecture alignment
Typography belongs to the shared design system and must be locale-aware. Any change must use the central loader and respect verified asset licensing.

## Verification criteria
Documentation accurately describes the active font setup; if changed, the central loader, locale assignment, and visual tests prove the intended family is rendered.
