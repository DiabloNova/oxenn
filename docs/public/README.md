## About this documentation

These pages explain OXENN's product model, assessment tracks, services, and core concepts. They are separate from internal engineering documentation and from the public marketing website.

Product scope and capability status are not the same thing. A documented or planned capability must not be interpreted as implemented, validated, connected to a live provider, or released unless the relevant page provides evidence for that status.

The documentation is maintained in Persian and English. Where the two versions differ, the discrepancy should be corrected rather than treated as a product-policy difference.
